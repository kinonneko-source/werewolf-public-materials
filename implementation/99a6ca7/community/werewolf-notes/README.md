# 六人狼人杀规则与记录

这是社区纯说明插件，提供固定规则与人工记录模板，**不包含可执行的确定性引擎，不可独立自动主持或保证恢复**。无 tools、scripts 或 MCP，不依赖剥离后不存在的文件。

示例任务：“解释六人局女巫与猎人的规则，给我一份空白人工记录表。”插件会提供规则和模板，不创建游戏、发私信或宣布结算。

## 规则

2狼、预言家、女巫、猎人、平民。无狼好人胜，狼数≥好人数狼胜，先处理死亡、猎人、遗言再判胜。夜间狼票最高票平票空刀；白天平票无人出局，不重投。女巫每局各一救一毒，每夜最多一种药；救刀口，仅首夜能自救，毒可选任一活人；刀毒重叠视作毒死。猎人刀死或投出可开枪，毒死不能开枪，弃权不开。首夜死者与白天投出者有一次遗言，其他夜死或中枪无遗言。主持公告不公开职业和狼队，玩家发言是玩家原话。
